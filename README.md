# Система управления академической информацией студентов

Веб-приложение для учёта студентов, преподавателей и учебных групп. 
Разработано в рамках дисциплины «Разработка веб-приложений на Python».

## Роли пользователей
- **Администратор**: управление студентами, преподавателями и группами.
- **Преподаватель**: просмотр своих групп и студентов в них.
- **Студент**: просмотр своих данных и редактирование контактов.
